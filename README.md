# PestControl

Система управління санітарними об'єктами, виїзними роботами, моніторинговими точками та документообігом.

**Pest Control Management Platform** — адмін-панель, клієнтський кабінет, моніторингові точки (QR/NFC), теплова карта активності, документи та PDF-звіти.

## Стек

- **Vue 3** + **TypeScript** + **Vite**
- **Tailwind CSS** — стилізація
- **Pinia** — стейт-менеджмент
- **Vue Router** — маршрутизація

## Розробка

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```

## Перевірка типів

```bash
npm run typecheck
```

## Деплой

CI/CD через GitHub Actions → rsync на Hetzner (порт 8083).

Необхідні GitHub Secrets:
- `DEPLOY_SSH_KEY` — приватний SSH-ключ
- `DEPLOY_HOST` — IP або хост сервера
- `DEPLOY_USER` — користувач SSH
- `DEPLOY_PATH` — шлях до папки на сервері

## Модулі (MVP)

- 📊 **Дашборд** — операційна панель керівника
- 👥 **Клієнти** — B2B та B2C сегменти
- 🏢 **Об'єкти** — заводи, склади, ресторани, офіси
- 🚗 **Виїзди** — обстеження, обробки, перевірки
- 📍 **Моніторинг** — QR/NFC точки, карта об'єкта, теплова карта
- 📄 **Документи** — акти, журнали, PDF-звіти
